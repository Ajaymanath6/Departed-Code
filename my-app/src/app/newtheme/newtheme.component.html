This search supports multiple use cases:
Search for multiple keywords Google OR Facebook.
Search within particular attributes.
Relational search using terms and connectors.

sticky_note_2 Note:

A maximum of 15 operators are allowed in a single query.

Allowed Connectors in Keyword Expressions

Connector Description Example
AND Find cases containing each of the terms joined by AND connectors. personal AND injury
OR Find cases containing any of the terms joined by OR connectors. order OR decision
NOT Find cases that do not contain the specified term. personal AND NOT injury
"[phrase]" Find the exact phrase placed between the quotation marks. "personal injury"
~ Find cases in which the specified words appear near each other. For example, "personal injury" ~ 5 targets cases in which the word "personal" appears within 5 words of the word "injury". "personal injury" ~ 5
( … ) Specifies the order in which connectors are to be applied in a keyword expression. personal AND (injury OR fall)

Fields and Connectors Searching

Field Description Example
caseNumber Find cases with the specified case number (i.e., docket number). caseNumber:"2020-L-007212"
caseName Find cases with the specified case title. caseName:"THOMAS P. CARNEY, INC. VS BEHLER JAMES Et Al"
Court Find cases in the specified court. (Court:(name:(New York)))
CaseStatus Find cases witih the specified case status. (CaseStatus:(name:Disposed))
CaseType Find cases of the specified case type. (CaseType:(name:Property))
Party Find cases involving the specified party. (Party:(name:Apple))
partyId Find cases involving a party with the specified partyId value. (Party:(partyId:"PRTYgu1ffe866484c2"))
PartyRole Find cases in which at least one party has the specified party role. (Party:((PartyRole:(name:"plaintiff"))))
AttorneyRepresentationType Find cases in which at least one party has the specified attorney representation type. (Party:(AttorneyRepresentationType:(name:"attorney represented")))
Attorney Find cases involving the specified attorney. (Attorney:(name:"David Boies"))
AttorneyType Find cases involving at least one attorney of the specified attorney type. (Attorney:((AttorneyType:(name:"Lead Attorney"))))
Judge Find cases involving the specified judge. (Judge:(name:"Posner"))
JudgeType Find cases involving at least one judge of the specified judge type. (Judge:((JudgeType:(name:"Magistrate"))))
CaseStats Find cases with the specified case statistics. (CaseStats:(partyCount:[10 TO 100]))
filedDate Find cases that were filed on the specified date or within the specified date range. filedDate:[2020-03-15 TO 2021-12-01]
lastFetchDate Find cases in which UniCourt last checked for updates on the specified date or within the specified date range. (lastFetchDate:[now-60d TO *])
lastFetchDateWithUpdates Find cases in which UniCourt last detected an update on the specified date or within the specified date range. (lastFetchDateWithUpdates:[now-6d TO *])
participantsLastFetchDate Find cases in which information cocnerning participants was last updated on the specified date or within the specified date range. (participantsLastFetchDate:[now-6d TO *])
DocketEntry Find cases in which at least one docket entry contains the specified text. (DocketEntry:(text:(Motion to Compel Responses) AND docketEntryDate:[2020-01-01T00:00:00 TO 2020-05-01T00:00:00]))
docketEntryDate Find cases in which at least one docket entry was made on the specified date or within the specified date range. (DocketEntry:(docketEntryDate:[2020-01-01T00:00:00 TO 2020-05-01T00:00:00])) AND (CaseStats:(allCaseDocumentCount:[0 TO 10]))
HearingDate Find cases with at least one hearing scheduled for the specified date or within the specified date range. (Hearing:(hearingDate:[now TO now+10d]))
HearingDate Search for cases where hearing is going to happen in 10 to 20days. (Hearing:(hearingDate:[now+10d TO now+20d]))
JurisdictionGeo Find cases in which the law of the specified state governs. (JurisdictionGeo:(state:"New York"))
Party Address Exists Find cases with Party addresses. (Party:(Contact:(Address:(stateName:*))))
Document Find cases with specific document name and preview is available for the document. (CaseDocument:(name:"civil case cover sheet" AND isPreviewAvailable:true))

Party Sub Filter Examples

Example Explanation
(Party:(name:google AND (PartyRole:(name:"plaintiff")))) Find cases involving at least one plaintiff whose name contains the term "Google".
